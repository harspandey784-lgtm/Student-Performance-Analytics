# Student Performance Analytics System

**Student:** Harsh Kumar Pandey

## Project objective
Analyze sample student marks and attendance using Python, NumPy, and Pandas. The system calculates totals, averages, grades, pass/fail status, class statistics, subject-wise averages, and top performers.

## Technologies
- Python 3
- Pandas
- NumPy
- CSV

## Files
```
student-performance-analytics/
├── main.py
├── students.csv
├── student_analysis_results.csv  
├── README.md
├── Project_Documentation.md

```

## Dataset
`students.csv` contains 20 sample records. Marks and attendance are sample values; replace them if actual class data is required.

## Grading rules
- A+: 90 and above
- A: 80 to below 90
- B: 70 to below 80
- C: 60 to below 70
- D: 50 to below 60
- E: 40 to below 50
- F: below 40

A student passes only if they score at least 40 marks in every subject. Attendance is summarized separately and does not affect pass/fail.

## Setup and execution
1. Install Python 3.
2. Open this folder in a terminal.
3. Install libraries:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the program:
   ```bash
   python main.py
   ```

The program prints the analyzed student table, class summary, subject-wise averages, and top five performers. It writes detailed output to `student_analysis_results.csv`.
